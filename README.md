# BuJet 🐾

A personal finance app built with Python, designed to grow into a self-hosted budgeting platform.

## Features

- Add and track expenses
- Save budget data locally with JSON
- Reset budget data
- Persistent data between sessions
- Currency formatting helpers
- Running balance calculations

## Planned Features

- Expense categories
- Monthly budgets
- Expense editing/deletion
- Charts and summaries
- Mobile-friendly interface
- APK/mobile app support

## Tech Stack

- Python
- JSON storage
- Git/GitHub

## Running the App

1. Clone the repository
2. Navigate to the project folder
3. Run:

```
python bujet.py
```
## Local Data

Personal budget data is stored locally in:

```
budget_data.json
```

This file is ignored via `.gitignore` and is not included in the repository.

An example structure is provided in:

```
example_budget_data.json
```

## Project Goal

BuJet started as a Python learning project and is gradually evolving into a fully featured personal budgeting application with self-hosting support.
